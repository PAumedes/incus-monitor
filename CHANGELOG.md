# Changelog

All notable changes to Incus Monitor. Versions follow [Semantic Versioning](https://semver.org/).

Each release section is generated by `make release` from the
[Conventional Commits](https://www.conventionalcommits.org/) since the previous tag. Do not edit
released sections by hand. To change what the next release says, write better commit messages.
The same entries go to `debian/changelog`.

## [1.0.0-rc.2] - 2026-10-07

### Features

- **ui:** offer Show log on a failed action (5811a3eb)
- **ui:** show the root disk usage of an instance when Incus reports it (0e0a7319)
- **ui:** show how many instances are running at the top of the menu (fba87d35)
- **ui:** show the port forwards of an instance in its expanded row (9a24a39e)
- **ui:** notify when a running instance stops without a menu action (ae3c6d73)
- **ui:** show notifications under Incus Monitor with the panel icon instead of System (c7b43413)

### Fixes

- **ui:** clear a failure notice after a later success and make the log view robust to pager settings (959dbdad)
- **ui:** clearer notification titles, locale-formatted counts, quieter screen reader names and tidier wording (3d955692)

### Documentation

- record the design review of B3, B4 and B8 (578adec3)

### Build and CI

- group make targets into test, build and release suites, add make doctor and readable output (668fa1c8)

## [1.0.0-rc.1] - 2026-10-06

### Features

- **core:** add Result type and IncusError union (0fc996da)
- **http:** add strict incremental HTTP/1.1 codec (d584371d)
- **incus:** decode and validate response envelopes (dd0e2427)
- **incus:** decode server and instance models (7b0f8184)
- **core:** discover the Incus socket with cancellation (a532a30c)
- **core:** compute metrics and format readouts (ba980062)
- **incus:** add Incus client over a transport port (41dfdae5)
- **incus:** gate on required API extensions (7e0f2846)
- **core:** add the polling monitor with actions and back-off (b812aabc)
- **adapters:** add Gio transport, clock, settings, probe and launcher (b494cc7c)
- **core:** present snapshots as a view model (dd14e943)
- **prefs:** add the Adw preferences window (1e3920b2)
- **ui:** add the panel indicator, menu and composition root (11b3b6f2)
- **i18n:** add the translation template and Spanish catalogue (4c4a3b45)
- **scripts:** add demo instances and make the nested shell follow your appearance (8fc5b49b)
- **core:** log the cause of a decode, api or timeout failure once per episode (051fd5fd)
- **ui:** add room before the copy button and a separator before Open Shell (32a2952e)
- **ui:** separate Open Shell from the lifecycle buttons (4169eb5e)
- **scripts:** add a headless screenshot harness and skills for verifying the extension live (73271a44)
- **ui:** group the expanded row in a faint panel so the next instance stands apart (352c0fff)
- **scripts:** reuse the desktop VM without rebooting and give it the host's demo instances (fd495598)

### Fixes

- **core:** treat a CPU usage of -1 as unavailable instead of failing the whole list (3445282b)
- **ui:** keep detail rows readable by not styling them as insensitive (5e4d9bbd)
- **ui:** align the rules and inset the Open Shell highlight in the expanded row (e79bb017)
- **ui:** show only the IPv4 address and keep rows in place while the menu is open (78866e7d)
- **ui:** release the highlight of the row header and Open Shell when the pointer leaves (76fb1e1b)
- **ui:** keep keyboard focus on the row while an action runs and return it afterwards (5ccf442b)
- **scripts:** start a stopped test VM, drop a stale per-user copy and set a login password (e6190990)
- **ui:** stop Open Shell from taking focus when an action settles and keep the address row height (d384cb2d)
- **scripts:** remove the previous package from the test VM before pushing the new one (d1828a69)
