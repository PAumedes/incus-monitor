# Changelog

All notable changes to Incus Monitor. Versions follow [Semantic Versioning](https://semver.org/).

Each release section is generated by `make release` from the
[Conventional Commits](https://www.conventionalcommits.org/) since the previous tag. Do not edit
released sections by hand. To change what the next release says, write better commit messages.
The same entries go to `debian/changelog`.

## [1.0.0-rc.2] - 2026-10-07

### Features

- **ui:** offer Show log on a failed action (b6246b00)
- **ui:** show the root disk usage of an instance when Incus reports it (9908ceac)
- **ui:** show how many instances are running at the top of the menu (5f449b51)
- **ui:** show the port forwards of an instance in its expanded row (7303bfe3)
- **ui:** notify when a running instance stops without a menu action (4268e328)
- **ui:** show notifications under Incus Monitor with the panel icon instead of System (56e839db)

### Fixes

- **ui:** clear a failure notice after a later success and make the log view robust to pager settings (0edd714b)
- **ui:** clearer notification titles, locale-formatted counts, quieter screen reader names and tidier wording (820fd20f)

### Documentation

- record the design review of B3, B4 and B8 (2af81f47)

### Build and CI

- group make targets into test, build and release suites, add make doctor and readable output (53b11174)

## [1.0.0-rc.1] - 2026-10-06

- **incus:** decode and validate response envelopes (8dc04a88)
- **incus:** decode server and instance models (f9ed5263)
- **core:** discover the Incus socket with cancellation (94325acf)
- **core:** compute metrics and format readouts (5b8a0a18)
- **incus:** add Incus client over a transport port (3d4cd9b4)
- **incus:** gate on required API extensions (417737ba)
- **core:** add the polling monitor with actions and back-off (cb51dd6a)
- **adapters:** add Gio transport, clock, settings, probe and launcher (f1b856cd)
- **core:** present snapshots as a view model (c47b53e8)
- **prefs:** add the Adw preferences window (e31fc052)
- **ui:** add the panel indicator, menu and composition root (09b7eb19)
- **i18n:** add the translation template and Spanish catalogue (d4c082b6)
- **scripts:** add demo instances and make the nested shell follow your appearance (7804d5b6)
- **core:** log the cause of a decode, api or timeout failure once per episode (c4ef092d)
- **ui:** add room before the copy button and a separator before Open Shell (adcb2930)
- **ui:** separate Open Shell from the lifecycle buttons (3b6e744b)
- **scripts:** add a headless screenshot harness and skills for verifying the extension live (4f9b0fda)
- **ui:** group the expanded row in a faint panel so the next instance stands apart (0814341f)
